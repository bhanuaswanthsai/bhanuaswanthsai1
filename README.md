## Featured Projects

### 🧠 [QuizCraft AI](https://github.com/bhanuaswanthsai/Quizcraft-ai)
AI-powered quiz platform built around a RAG pipeline — users upload PDF notes, which are chunked and embedded via Gemini's `text-embedding-004` model into a Pinecone vector index (768-dim, cosine similarity), then queried to generate contextual MCQs from their own content. Supports real-time multiplayer rooms for up to 50 players via Socket.IO with server-synced timers and live leaderboards, deployed with a Docker + GitHub Actions CI/CD pipeline.

`React` `Node.js` `Express` `MongoDB` `Socket.IO` `Gemini API` `Pinecone` `Docker` `GitHub Actions`

### 🎨 [DrawSync — Collaborative Whiteboard](https://github.com/bhanuaswanthsai/White_board_sharing)
Real-time collaborative whiteboard supporting multi-user simultaneous drawing, shape tools, and freehand sketching, synchronized across sessions with sub-100ms latency via Socket.IO. Full MERN stack containerized with Docker; room-based sessions persist in MongoDB so users can rejoin active boards via shared room codes.

`React` `Node.js` `Express` `MongoDB` `Socket.IO` `Docker`

### 🔐 [Secure Web App — NGINX Reverse Proxy](https://github.com/bhanuaswanthsai/Secure-Web-App-Using-Nginx-Reverse-Proxy)
Defense-in-depth security architecture on a hardened Linux server: an NGINX reverse proxy routes all HTTPS traffic to a Flask backend, with SSL/TLS encryption via OpenSSL and port access restricted to 443/80 through FirewallD rules, combining network-layer, transport-layer, and application-layer security controls.

`Linux` `NGINX` `Flask` `OpenSSL` `FirewallD`
